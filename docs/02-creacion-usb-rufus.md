# 02 - Creación del USB con Rufus

## Objetivo

Crear un dispositivo USB arrancable para instalar MX Linux XFCE.

## Herramienta utilizada

- Rufus

## Configuración utilizada

- Imagen ISO: MX Linux XFCE x64
- Esquema de partición: MBR
- Sistema destino: BIOS o UEFI
- Sistema de archivos: FAT32

## Procedimiento

1. Descargar la ISO desde el sitio oficial de MX Linux.
2. Abrir Rufus.
3. Seleccionar la memoria USB.
4. Seleccionar la imagen ISO.
5. Configurar MBR.
6. Crear el USB.

## Resultado

USB de instalación creado correctamente.
