# 03 - Instalación de MX Linux

## Arranque desde USB

- Tecla ESC para acceder al menú de arranque.
- Selección del dispositivo USB.

## Configuración seleccionada

- Uso del disco completo.
- Eliminación de Windows 10.
- Swap de 4096 MB.
- Hibernación habilitada.
- ZRAM habilitado.
- Samba habilitado.

## Configuración de red

- Nombre del equipo: ASUS53-GIO
- Dominio: SMARTCODE

## Usuario creado

- Usuario: giovospo

## Resultado

Instalación completada correctamente.
